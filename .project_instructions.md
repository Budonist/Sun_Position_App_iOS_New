## Sonnenschein iOS App

### Architecture
- Native SwiftUI app (iOS 18+), no backend, no persistence needed
- Computation engines (SolarEngine + ShadowEngine) from /home/ubuntu/sonnenschein/ copied into Sources/Engine/
- Geodata (turandot_buildings.json, ~5.4MB) bundled as NSDataAsset "TurandotBuildings" in Assets.xcassets
- PLZ 10961 Berlin coverage only

### Design System
- Sun yellow: #F2B705, Shadow slate: #4A5361, Night: #121417
- Background: #FAF7F0 (light) / #121417 (dark)
- Surface: white / #1E2126
- All times: monospaced digits, locale de_DE, timezone Europe/Berlin
- SF Pro typography, Dynamic Type text styles

### App Structure
- App entry: SonnenscheinIosApp → RootView → MapScreen
- MapScreen: Full-bleed Map with floating controls + persistent SolarResultSheet
- SolarResultSheet: Bottom sheet with detents [.height(140), .medium, .large]
- SolarComputationService: Actor wrapping engines, coverage bounds check, 1-min sampling + bisection
- LocationProvider: CLLocationManager wrapper for "Mein Standort" button
- All user-facing strings in German

### Key Technical Decisions
- Engine sources copied directly (no Swift package support on platform)
- `import SolarEngine` removed from ShadowEngine (single target)
- GeometryStore extended with `load(from: Data)` for NSDataAsset loading
- Observer height: 1.2m above ground
- Coverage bounds: lat 52.480–52.510, lon 13.375–13.430

### Capabilities
- Location (foreground only) for "Mein Standort" button
